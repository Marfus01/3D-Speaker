在3D-Speaker/egs/3dspeaker/speaker-diarization/local/self_supervised_finetune.py中，我已经完成了语音部分自监督学习的pipeline。该pipeline主要包含以下几个步骤：
1. 初始化：调用run_clustering_and_evaluation()，获取说话人、人脸聚类增强结果，并评估说话人识别的acc。此外，根据视觉、听觉标签的一致性，构建pseudo valid set，用于确定每个round将说话人模型训练多少个epoch。
2. 迭代训练：在每个round中，利用说话人聚类结构构建dataset和dataloader，在speaker model的上层接一个mlp分类头，微调speaker model中的最后几层dense layer。每训练完一个epoch，计算valid set的acc，选择最佳epoch，并保存其模型参数和预测结果。随后，调用
run_clustering_and_evaluation()，对预测结果做增强，获得新的pseudo label及其acc，供下一轮微调使用。

由于我的聚类增强是用nested hmm实现的，该hmm不仅能对说话人标签做矫正，还能对关键帧中所有人脸的标签做矫正，从而提升人脸识别的准确率。因此，我希望在上述pipeline中，加入对人脸识别模型的微调。具体而言，请你修改self_supervised_finetune.py，完成以下内容：

9. 像speaker 部分一样，保存最佳epoch的人脸模型权重和预测标签、不确定度和embedding。

# 自监督微调中，人脸pseudo valid set的构建思路：
1. 计算每一帧里，各个**主要**角色出现的次数。要求次数>1的情况数尽可能小
2. 筛选只有一个人出现，且该人是说话人的部分数据，作为pseudo valid set
3. 将初始的人脸标签作为pseudo valid set
4. 计算embedding与mlp给出分类标签的某种一致性

# 自监督微调用于训练的样本集：
为了避免未对齐小簇加权后对模型训练产生负面影响，有两种思路：
1. 方法1：只使用已经经过人脸，语音对齐的部分样本（process, 生活大爆炸上，acc=0.9068；我爱我家上，acc=0.9567）。推理也在这部分样本上面做，剩余样本仍采用原始聚类结果。
2. 方法2：在保存pseudo label face时，直接将未对齐样本的标签设置为-1（process all: 生活大爆炸上，acc=0.9074；我爱我家上，acc=0.8491）。推理时，在所有样本上进行。
> 注意到，方法2中，未对齐样本的标签在评估时相当于均被视作了-1。
> 在生活大爆炸上，未对齐、有标注的样本上的标签确实为-1，所以才会使得acc_Others提升，而ground truth标签为其它类的样本acc不变。
> 在我爱我家上，未对齐、有标注的样本中，很多实际标签不为-1，所以才会使各个类的acc均下降。

综合考虑，方案2开发成本低，选用该方案。
