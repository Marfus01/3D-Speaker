在3D-Speaker/egs/3dspeaker/speaker-diarization/local/self_supervised_finetune.py中，我已经完成了语音部分自监督学习的pipeline。该pipeline主要包含以下几个步骤：
1. 初始化：调用run_clustering_and_evaluation()，获取说话人、人脸聚类增强结果，并评估说话人识别的acc。此外，根据视觉、听觉标签的一致性，构建pseudo valid set，用于确定每个round将说话人模型训练多少个epoch。
2. 迭代训练：在每个round中，利用说话人聚类结构构建dataset和dataloader，在speaker model的上层接一个mlp分类头，微调speaker model中的最后几层dense layer。每训练完一个epoch，计算valid set的acc，选择最佳epoch，并保存其模型参数和预测结果。随后，调用
run_clustering_and_evaluation()，对预测结果做增强，获得新的pseudo label及其acc，供下一轮微调使用。

由于我的聚类增强是用nested hmm实现的，该hmm不仅能对说话人标签做矫正，还能对关键帧中所有人脸的标签做矫正，从而提升人脸识别的准确率。因此，我希望在上述pipeline中，加入对人脸识别模型的微调。具体而言，请你修改self_supervised_finetune.py，完成以下内容：
1. 修改cmd_compute_acc_spk和compute_speaker_accuracy，在其输入参数中增加'modal'，使其能够同时处理speaker、face acc的评估与计算。
2. 在run_clustering_and_evaluation()中，除了对speaker acc的评估之外，增加对face acc的评估，并将两个acc都返回。
3. 人脸模态无需加载、定义seg_ids_unreliable，认为所有人脸标签均不可靠。暂时不定义人脸的pseudo_valid_label_dic。
4. 参考egs/3dspeaker/speaker-diarization/local/verify_face_pyorch_embed.py，定义face embedding model的初始化
5. 构建人脸的dataset。具体而言
    a. 所有关键帧人脸的裁剪图片都保存在dataset/<tv_series>/midframe_faces/下，路径格式为{dataset_root}/midframe_faces/{episode_id}/{episode_id}_{face_idx}.jpg，其中face_idx是该subseg中的人脸序号，
    b. 参照NewFaceRecognitionModel.preprocess，对人脸图片进行预处理
    c. 从pseudo_labels_faces_mid_frame.json中，读取每个关键帧人脸的pseudo label。json内容形如{"E01-1_0": 0, "E01-1_1": 1, ...}
    d. 参照PseudoLabelDataset，定义label2idx，idx2label，class_weights，label_weights等。请注意，__getitem__只需要返回图片tensor和label。
6. 使用与说话人相同的bs，构建人脸的dataloader
7. 在每个round中，增加对人脸模型的微调。具体而言:
    a. 实例化MLPClassifier，定义一个人脸模型专用的分类头，并在round=0时，先冻结face embedding model权重，warm up该分类头若干个epoch
    b. 使用（如有必要，请适当修改）unfrozen_model_layers函数，解冻face embedding model.output_layer（在egs/3dspeaker/speaker-diarization/local/vision_tools/face_recognition_pytorch.py中定义）
    c. 使用train_one_epoch（如有必要，请适当修改），对人脸模型和人脸分类头进行微调
8. 在每个epoch之后，直接在标注数据上计算人脸的acc，并据此以与说话人相同的stop criteria选择最佳epoch。
9. 像speaker 部分一样，保存最佳epoch的人脸模型权重和预测标签、不确定度和embedding。
10. 利用每个round的audio、visual prediction，调用run_clustering_and_evaluation()，获得新的pseudo label及其acc，供下一轮微调使用。

请注意，现在我的代码中，一些变量的命名并没有区分speaker和face，例如pseudo_valid_label_dic、best_epoch_model_path等。请你在修改时，注意区分、重命名这些变量，以免混淆。

# 自监督微调中，人脸pseudo valid set的构建思路：
1. 计算每一帧里，各个**主要**角色出现的次数。要求次数>1的情况数尽可能小
2. 筛选只有一个人出现，且该人是说话人的部分数据，作为pseudo valid set
3. 将初始的人脸标签作为pseudo valid set
4. 计算embedding与mlp给出分类标签的某种一致性
